# SciReader EN–RU

Научные статьи на английском с параллельным русским переводом.

**SciReader EN–RU** — проект веб-приложения для чтения научных PDF: оригинал и перевод рядом, связанные предложения, подсказки к формулам и помощь в произношении. Имя репозитория: `scireader-en-ru`.

## Статус

**Технический прототип.** Доступен ридер страниц 3–5 демонстрационной статьи: парная подсветка, переключаемая прокрутка, подсказки формул и ручное исправление привязок. Остальные возможности первой версии находятся в разработке. [Результаты проверки и ограничения](docs/prototype.md).

## Локальный запуск

Требования: Node.js 24 и npm.

```sh
npm ci
npm run dev
```

Проверка типов и сборка: `npm run build`. Браузерные тесты: `npm test` (Chromium и Firefox Playwright). В Windows PowerShell при ограничении запуска npm.ps1 используйте `npm.cmd`.

Прототип использует подготовленный пример. Изменения привязок и формул действуют до перезагрузки вкладки.

## Возможности первой версии

- **Параллельное чтение:** оригинальный PDF и русский перевод с взаимной подсветкой предложений и визуальным соединением выбранных фрагментов.
- **Связанная прокрутка:** включена по умолчанию; можно переключиться на независимую прокрутку панелей.
- **Библиотека статей:** несколько отрывков с общим переводом, контрольные точки и восстановление позиции чтения.
- **Отрывки заданного объёма:** подсчёт символов без пробелов с завершением последнего предложения и предпросмотром границ.
- **Формулы и произношение:** LaTeX, английские подсказки по чтению формул, озвучка текста и переход к словарю.
- **Локальные данные:** сохранение в выбранной папке или IndexedDB, импорт и экспорт для переноса между компьютерами.

## Как устроен перевод

Пользователь загружает PDF, выбирает отрывок и получает подготовленный запрос для внешнего ИИ. Результат импортируется в приложение, проверяется на соответствие исходным фрагментам и доступен для ручного редактирования.

Первая версия не требует платного API или собственного сервера. Доступность и лимиты внешнего ИИ зависят от выбранного сервиса. Сохранённые материалы остаются доступными независимо от него.

## Поддержка документов

Первая версия рассчитана на настольные браузеры и **PDF с текстовым слоем**. Сканы и OCR не входят в её объём. Оригинальная вёрстка сохраняется; таблицы и рисунки видны в PDF, но не переводятся. Формулы, таблицы, рисунки и их подписи исключаются из подсчёта объёма отрывка.

## Технологии

Планируемый стек: **React · TypeScript · Vite · PDF.js · MathJax · IndexedDB · PWA · Playwright**. Размещение — GitHub Pages. Подготовленные материалы планируется поддержать для чтения без сети; внешние сервисы доступны при наличии соединения.
