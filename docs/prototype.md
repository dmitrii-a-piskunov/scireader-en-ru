# SciReader EN–RU — первый PDF-прототип

Дата: 2026-11-05. Статус: локальный технический прототип, не готовая первая версия приложения.

## Запуск

Нужен Node.js 24 и npm. Из корня репозитория:

```sh
npm ci
npm run dev
```

В Windows PowerShell при ограничении запуска npm.ps1 используйте `npm.cmd`.
Локальный адрес выводится Vite при запуске.

```sh
npm run typecheck
npm run build
npm run preview
npm test
```

Браузерные проверки используют Chromium и Firefox Playwright. Если браузеры ещё не установлены: `npx playwright install chromium firefox`.

## Реализованный срез

- Страницы 3–5 предоставленной статьи в исходном PDF.
- 42 подготовленных фрагмента из Home Reading 3: 38 текстовых и 4 отдельные формулы.
- Сопоставление подготовленного английского текста с текстовым слоем PDF и получение областей через DOM Range.
- Парная подсветка, выбор мышью и клавиатурой, соединительная фигура. Наведение не прокручивает панели.
- Независимая и связанная прокрутка; связанная включена по умолчанию. Начало опорного русского предложения выравнивается с началом английского фрагмента; отступы в панели перевода позволяют выровнять также первый и последний фрагменты. Выбор и смена масштаба сохраняют выравнивание.
- Масштаб 75–200%; проверены 75%, 100% и 150%.
- Английское чтение всех 21 подготовленных математических фрагментов отрывка: 17 встроенных выражений/переменных и 4 отдельных уравнения. Нажатие прямо на формулу в PDF или переводе открывает карточку рядом с ней; формулы доступны с клавиатуры и имеют подсказку при наведении.
- Постоянная панель действий с привязкой: выбор и Esc не изменяют высоту предложений. Esc убирает также наведение и оставшийся фокус.
- Редактирование LaTeX и чтения, исправление области формулы.
- Замена привязки предложения одним или несколькими прямоугольниками с предпросмотром, применением, отменой и сбросом к исходной привязке.

Правки хранятся только в памяти вкладки. Перезагрузка их сбрасывает, о чём сообщает интерфейс.

## Результаты проверки

- `npm run build`: успешно, включая TypeScript.
- `npm test`: 18 проверок пройдены — по 9 в Chromium и Firefox. Ошибок выполнения JavaScript в этих сценариях не зарегистрировано. Дополнительно проверены все 21 области формул с обеих сторон, индивидуальное чтение четырёх формул примера, близость карточки к формуле, точное выравнивание после выбора/прокрутки/масштабирования и неизменность геометрии текста после Esc.
- Найдены привязки всех 42 подготовленных фрагментов. Это включает 4 вручную подготовленные области отдельных формул; данное число не является показателем автоматического распознавания формул.
- Проверены выбор пары в обе стороны, клавиатурный переход, отсутствие прокрутки при наведении, переключение режимов, устойчивость прокрутки, масштабирование, применение и сброс ручной привязки, сохранение ручной области формулы после изменения масштаба и отмена правки.
- Собранная версия дополнительно открыта через Vite preview: PDF, все 42 привязки и карточка формулы загрузились без ошибок выполнения.
- Снимки Chromium визуально осмотрены: исходный PDF, перевод, подсветка, соединительная фигура и область уравнения Беллмана. Полная построчная визуальная проверка всех фрагментов не выполнялась.
- Первые проверки обнаружили ошибки тестовых селекторов (служебные canvas PDF.js) и позиции тестового выделения; они исправлены до итогового прогона. При визуальной проверке уточнены исходные области формул.

## Ограничения и выводы

Главная гипотеза подтверждена для подготовленной статьи: оригинальный PDF можно связать с переводом, подсвечивать текст без перестройки вёрстки и сохранять области при масштабировании.

Обобщаемость пока не доказана:

- Автоматического разбиения произвольной статьи на предложения и загрузки другого PDF нет.
- Поиск работает внутри одной страницы. Предложения, переходящие между страницами, ещё не поддержаны и не проверены.
- Поиск использует упрощённую нормализацию: регистр, совместимые Unicode-символы, пробелы и пунктуация. При повторяющемся тексте выбирается первое совпадение; для полной версии нужен поиск с контекстом и выявлением неоднозначности.
- В тестовом исходнике исправлены известные ошибки старого HTML: a0/s0 вместо штрихов; при сопоставлении кортежа убраны ошибочно извлечённые h/i. Сам HTML и PDF сохранены без изменения.
- Начальные области отдельных формул подготовлены по координатам текста PDF. Их распознавание из произвольного PDF не реализовано. Встроенные выражения текущего отрывка размечены в подготовленных данных и автоматически привязаны к диапазонам внутри известных предложений; это не универсальное распознавание формул.
- LaTeX и чтение подготовлены как демонстрационные данные; внешний ИИ не вызывался и качество ChatGPT/DeepSeek этим прототипом не сравнивалось.
- Политика соединителя для невидимой пары: скрывать фигуру, пока обе стороны не видны. Это технический выбор прототипа для оценки, а не окончательное продуктовое решение.
- При отсутствии видимых привязанных фрагментов синхронизация приостанавливается. Если прокрутка PDF упирается в начало или конец доступного диапазона, точное выравнивание может быть ограничено.
- Повороты страниц, другие макеты и Safari пока не проверены.
- Библиотека, постоянное хранение, подсчёт символов, импорт ИИ, озвучка, словарь, PWA и публикация не реализованы.
- Сборщик сообщает о большом основном JS-файле (около 2.3 МБ до gzip); PDF.js и MathJax ещё не разделены на отложенно загружаемые части.

## Организация кода

- `prototype/src/App.tsx` — экран чтения, навигация, прокрутка и исправления.
- `prototype/src/PdfPage.tsx` — страница PDF, слои и выделение областей.
- `prototype/src/pdf.ts` — PDF.js, индекс текста и получение координат.
- `prototype/src/model.ts`, `fixture.json` — подготовленные фрагменты и начальные формулы.
- `prototype/src/math.ts`, `MathView.tsx` — локальный рендеринг LaTeX через MathJax.
- `prototype/src/FormulaPopover.tsx` — карточка чтения, привязанная к формуле в соответствующей панели.
- `scripts/extract-fixture.py` — повторное извлечение пар из неизменённого HTML-примера.
- `tests/reader.spec.ts` — браузерные сценарии.

Vite подаёт только исходную статью как `sample.pdf` и включает её в локальную сборку прототипа. Остальные материалы references/ не копируются. Публикация этой сборки пока не выполнялась; для полноценного приложения образец должен быть отделён от пользовательских документов.

## Следующий шаг

Оценить ридер вручную на подготовленной статье, затем расширить эксперимент на переход предложения через страницу и другой макет PDF. После этого уточнить алгоритм привязки и формат данных; отдельно проверить контракт обмена с внешним ИИ.
