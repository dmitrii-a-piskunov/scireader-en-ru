3. Key Concepts and Algorithms of Reinforcement Learning
Reinforcement learning is a strategy that encourages an agent to take action and inter-
act with an environment in order to maximize the total rewards. The agent–environment
interaction process is shown in Figure 2. The agent takes action and receives feedback from
the environment in the form of rewards or punishments. The agent uses this feedback to
adjust its behavior and improve its performance over time.
An autonomous agent observes the state s(t) at a time step t and then interacts with
the environment using an action a(t), reaching the next state s(t + 1) in the process. Once a
new state has been achieved, the agent receives a reward correlated with that state r (t + 1).
The agent’s goal is to find an optimal policy, i.e., the optimal action in any given state.
Unlike other types of machine learning—such as supervised and unsupervised learning—
reinforcement learning can only be thought about sequentially in terms of state-action pairs
that appear one after the other.
RL assesses actions by the outcomes, i.e., the states, they achieve. It is goal-oriented
and seeks to learn sequences of actions that will lead an agent to accomplish its goal or
optimize its objective function. An example of the RL objective function is:
\(\displaystyle \sum_{t=0}^{\infty}\gamma^{t}r\bigl(s(t),a(t)\bigr)\)(1)
This objective function measures all of the rewards that we will receive from running
through the states while exponentially increasing the weight γ.
Two important concepts of RL are Monte Carlo learning, which is a naive idea in
which the agent interacts with the environment and learns about the states and rewards,
and temporal difference (TD) learning, i.e., updating the value at every time step rather
than being required to wait to update the values until the end of the episode.
Although it is difficult to make a standardized classification of RL algorithms due
to their wide modularity, many current studies tend to divide them into value-based,
policy-based, and actor–critic algorithms (see Figure 3).
3.1. Markov Decision Process and RL
A Markov decision process (MDP) is defined as a tuple hS, A, r, T, γi where S stands
for a set of states; A stands for actions; r, S × A → R denotes the function specifying
a reward of taking an action in a state; T : S × A × S → R denotes the state transition
function; and γ stands for the discount factor implying that a reward obtained in the future
is worth a smaller amount than an immediate reward. Solving an MDP involves finding a
policy that determines the optimal action for each state, with the goal of maximizing the
long-term discounted expected reward. This policy should be optimal with respect to the
MDP’s reward structure and discount factor.
3.2. Value-Based RL
3.2.1. Q-Learning
Q-learning [16] is a value-based TD method of reinforcement learning that uses Q-
values (also called state-action values) to iteratively develop the actions of the learning
agent. Q-learning learns the Bellman action-value function Q(s, a), which estimates how
good it is to take an action at a given state.
\(\displaystyle Q(s,a)=r(s,a)+\gamma\max_{a}Q(s\prime,a)\)(2)
The Bellman action-value equation describes how to calculate the Q-value for an action
taken from a particular state, s. It is calculated as the sum of the immediate reward for
the current state and the discounted optimal Q-value for the next state, denoted by γ. In
Q-learning, the Q-value is updated using the following rule: The new Q-value is equal to
the old Q-value plus the temporal difference error. This update can be framed as trying to
minimize a loss function, such as the mean squared error loss:
\(\displaystyle L=\left(r+\gamma\max_{a\prime}Q(s\prime,a\prime;\theta\prime)-Q(s,a;\theta)\right)^{2}\)(3)
3.2.2. SARSA
The SARSA [17] algorithm is a policy-based variant of the well-known Q-learning
algorithm. Unlike Q-learning, which is an off-policy technique that learns the Q-value
using a greedy approach, SARSA is an on-policy technique that uses the action taken by
the current policy to learn the Q-value. To update Q-values, we use:
\(\displaystyle Q(s,a)=Q(s,a)+\alpha\left[R+\gamma Q(s\prime,a\prime)-Q(s,a)\right]\)(4)
SARSA is a type of on-policy reinforcement learning algorithm, meaning that it learns
the value of actions based on the policy that is currently being followed. In SARSA, the
next action, a0 , is chosen using the same epsilon-greedy policy as the action that led to
the current state, s0 . One advantage of this approach is that SARSA is able to learn a near-
optimal policy while still allowing for some exploration.

3. Основные понятия и алгоритмы обучения с подкреплением

Обучение с подкреплением — это стратегия, побуждающая агента действовать и взаимодействовать со средой, чтобы максимизировать суммарное вознаграждение. Процесс взаимодействия агента со средой показан на рисунке 2. Агент выполняет действие и получает обратную связь от среды в виде вознаграждений или наказаний. Агент использует эту обратную связь, чтобы корректировать своё поведение и со временем улучшать результаты.

Автономный агент наблюдает состояние s(t) на временном шаге t, затем взаимодействует со средой, выполняя действие a(t), и в результате переходит в следующее состояние s(t + 1). После достижения нового состояния агент получает связанное с ним вознаграждение r(t + 1). Цель агента — найти оптимальную стратегию, то есть оптимальное действие для любого заданного состояния. В отличие от других видов машинного обучения, таких как обучение с учителем и без учителя, обучение с подкреплением можно рассматривать только последовательно, как пары «состояние — действие», возникающие одна за другой.

Обучение с подкреплением оценивает действия по результатам, то есть по состояниям, к которым они приводят. Оно ориентировано на цель и стремится освоить последовательности действий, которые позволят агенту достичь цели или оптимизировать целевую функцию. Пример целевой функции обучения с подкреплением:

\(\displaystyle \sum_{t=0}^{\infty}\gamma^{t}r\bigl(s(t),a(t)\bigr)\)(1)

Эта целевая функция учитывает все вознаграждения, которые будут получены при прохождении состояний, при этом вес γ изменяется экспоненциально.

Два важных понятия обучения с подкреплением — обучение методом Монте-Карло, основанное на простой идее взаимодействия агента со средой и изучения состояний и вознаграждений, и обучение на основе временных различий (TD), при котором оценка обновляется на каждом временном шаге, а не только после завершения эпизода.

Хотя из-за высокой модульности алгоритмов обучения с подкреплением трудно создать единую классификацию, многие современные исследования разделяют их на алгоритмы на основе ценности, на основе стратегии и типа «актор — критик» (см. рисунок 3).

3.1. Марковский процесс принятия решений и обучение с подкреплением

Марковский процесс принятия решений (MDP) определяется кортежем ⟨S, A, r, T, γ⟩, где S — множество состояний; A — действия; r, S × A → R — функция, задающая вознаграждение за действие в определённом состоянии; T : S × A × S → R — функция перехода между состояниями; а γ — коэффициент дисконтирования, означающий, что будущее вознаграждение ценится меньше немедленного. Решение MDP предполагает поиск стратегии, определяющей оптимальное действие для каждого состояния с целью максимизации долгосрочного ожидаемого вознаграждения с учётом дисконтирования. Такая стратегия должна быть оптимальной с учётом структуры вознаграждений MDP и коэффициента дисконтирования.

3.2. Обучение с подкреплением на основе ценности

3.2.1. Q-обучение

Q-обучение [16] — это метод обучения с подкреплением на основе временных различий и ценности, использующий Q-значения (также называемые значениями пар «состояние — действие») для последовательного совершенствования действий обучающегося агента. Q-обучение осваивает функцию ценности действия Беллмана Q(s, a), которая оценивает, насколько полезно выполнить определённое действие в заданном состоянии.

\(\displaystyle Q(s,a)=r(s,a)+\gamma\max_{a}Q(s\prime,a)\)(2)

Уравнение Беллмана для ценности действия описывает, как вычислить Q-значение действия, выполненного из определённого состояния s. Оно вычисляется как сумма немедленного вознаграждения для текущего состояния и дисконтированного оптимального Q-значения для следующего состояния, с коэффициентом γ. В Q-обучении Q-значение обновляется по следующему правилу: новое Q-значение равно прежнему Q-значению плюс ошибка временной разности. Это обновление можно представить как попытку минимизировать функцию потерь, например среднеквадратичную ошибку:

\(\displaystyle L=\left(r+\gamma\max_{a\prime}Q(s\prime,a\prime;\theta\prime)-Q(s,a;\theta)\right)^{2}\)(3)

3.2.2. SARSA

Алгоритм SARSA [17] — вариант известного алгоритма Q-обучения, основанный на стратегии. В отличие от Q-обучения, которое является внестратегийным методом и осваивает Q-значение с помощью жадного подхода, SARSA — стратегийный метод, использующий действие, выбранное текущей стратегией, для обучения Q-значению. Для обновления Q-значений используется:

\(\displaystyle Q(s,a)=Q(s,a)+\alpha\left[R+\gamma Q(s\prime,a\prime)-Q(s,a)\right]\)(4)

SARSA — алгоритм обучения с подкреплением на основе текущей стратегии: он оценивает действия в соответствии со стратегией, которой агент следует в данный момент. В SARSA следующее действие a′ выбирается по той же эпсилон-жадной стратегии, что и действие, приведшее к текущему состоянию s′. Одно из преимуществ этого подхода состоит в том, что SARSA может освоить почти оптимальную стратегию, сохраняя возможность некоторого исследования среды.
